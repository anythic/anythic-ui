First release of `@anythic/ui`: React components for AI interfaces.

- Chat: `Conversation`, `Message`, `PromptInput` (with attachments) and `AttachmentList`
- Replies: `StreamingText`, `Markdown` with streaming repair, `CodeBlock`, `Citation` and `Sources`
- Agents: `ReasoningBlock`, `ToolCall`, `ToolApproval` and `Plan`
- Coding agents: `CodeDiff`, `Terminal` and `ContextUsage`
- `useTextStream` for reading any text stream, and theming with shadcn/ui-compatible tokens
